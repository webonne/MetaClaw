# IT 智能排障系统 · 设计文档

基于 MetaClaw 元学习平台构建的 IT 智能排障能力，目标是把故障处理从
「人工翻系统 + 经验判断」升级为「告警驱动 · 智能路由 · 自动取证 · 人机协同诊断 · 知识闭环」。
