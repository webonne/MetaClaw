# IT 智能排障系统 · 设计文档

基于 MetaClaw 元学习平台构建的 IT 智能排障能力，目标是把故障处理从
「人工翻系统 + 经验判断」升级为「告警驱动 · 智能路由 · 自动取证 · 人机协同诊断 · 知识闭环」。

## 文档

- [架构与演进蓝图](./architecture-blueprint.html) — 分层架构、双路脊柱（确定性 / LLM
  兜底）、全过程运转图、三个数据契约、观测云 DQL 取证方案、L0→L5 演进路线，以及
  部门级复用 / 平台化（复合键路由、公共/业务两层知识库、分层接入）。
- [交互原型 · 版式 A](./console-prototype.html) — 单故障详情页（IM 优先 · 纵向）：IM 卡片
  \+ 故障上下文 Web 台，以真实故障 `903001 数据库访问异常` 填充。证据可展开、恢复动作
  三分级可执行、写操作二次确认并留痕、转派带全上下文、观测云降级态可切换。
- [交互原型 · 版式 B](./console-prototype-b.html) — 值班驾驶舱（三栏 · 应用式）：左故障队列
  \+ 中处置区 + 右证据检视器，含 `903001` / `901002` 两个可切换故障。面向"同时盯多个
  故障"的值班场景。两版共用同一「诊断结论对象」，可并存为两个入口。

> 两款均为单文件、零外部依赖，浏览器直接打开即可交互，用于对比布局取向。

> HTML 文件在浏览器中打开阅读 / 交互效果最佳。
